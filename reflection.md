# Reflection

## 1. What did you ask Copilot to help you build? How did you break down the problem?

I originally asked GitHub Copilot to help me build a simple short-video social media website. I wanted the application to have a short-video style layout, interactive buttons, and basic social media features. I planned to break the project into smaller parts, including the HTML structure, CSS styling, and JavaScript functionality.

I also tried to use GitHub Copilot to help me develop the application. However, Copilot repeatedly stayed on "Working..." and did not provide a response. I documented this issue with a screenshot. My instructor explained that I could use another AI tool if Copilot was unavailable, so I continued the project using ChatGPT.

![Copilot stuck](copilot-stuck.png)

## 2. How did your approach to asking questions change as you worked?

At first, I was trying to get the application started and understand how the different files worked together. As I continued, I learned that it was easier to work on one part of the application at a time. Instead of trying to create everything at once, I focused on the HTML structure, styling, and JavaScript functionality separately.

Using ChatGPT also helped me understand what changes needed to be made to specific files.

## 3. What parts of the development process with GitHub Copilot surprised you?

One thing that surprised me was that GitHub Copilot did not always respond when I tried to use it. It stayed on "Working..." even after I tried troubleshooting it. This showed me that AI development tools can sometimes have technical issues and that developers need to know how to continue working when a tool is unavailable.

My instructor allowed me to use another AI tool, so I was able to continue the assignment.

## 4. What did you learn about the technology you used that you didn't know before?

I learned more about how HTML, CSS, and JavaScript work together to create a website. HTML creates the structure of the page, CSS controls the appearance, and JavaScript adds interactive features.

I also learned more about Git and GitHub. I practiced adding files, committing changes, and pushing my project to a GitHub repository.

## 5. What would you do differently if you had to build this again?

If I built this application again, I would plan the features before starting the project. I would also test each feature as I added it instead of waiting until the end. I would use more specific prompts when working with AI tools so that I could get more focused help.

I would also make sure I had a backup plan if an AI development tool stopped working.
